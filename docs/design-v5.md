## Curation rationale

Design: Penpot for interface design, Blender for 3D, and Krita for painting. AI: Ollama for local models, Aider for coding assistance, and Continue for editor workflows. Everyday: Joplin for notes, LocalSend for nearby sharing, Bitwarden for passwords. Media: OBS Studio for recording, Audacity for audio editing, and VLC for playback. These are complementary starting points from the verified catalog, not a universal ranking. Each opens its actual detail page; full collections retain all existing entries and source links.

All ten catalog categories remain available. Featured folders introduce four use cases rather than hiding the rest of the library. AI execution and public submissions remain deferred.

## Final visual review

The rendered light and dark layouts were compared with the supplied reference at phone, tablet, and desktop sizes. Four white shells hold local project artwork; their colored folder fronts have one fixed title, short use-case text, a real tool count, and a collection link. Tool names stay visible and stationary. The hover lift and small open-detail badge belong only to the object under the pointer. No text replacement, automatic carousel, timers, or lower preview band remain.

Desktop navigation groups the ten real categories under Explore, keeps personal lists under Your library, and derives counts from the catalog. Category routes preserve platform/display filters while clearing previous text search, topic, and pagination. A compact rail and the existing topic browser cover tablets; the mobile category control remains in the main flow. Scrollable rail content preserves access to the pinned profile footer in shorter windows.
